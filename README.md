# 🤖 AI Content Generator

An AI-powered content generator that helps users create:

- 📱 WhatsApp captions
- 📢 Advertisements
- 📝 School content
- 🎵 Songs
- 📣 Social media posts
- ✍️ General written content

## Technology

- HTML
- CSS
- JavaScript
- Node.js
- Express
- OpenAI API

## Project Status

🚧 Under development

## Security

The OpenAI API key must be stored securely as an environment variable.

Never put the API key directly inside the frontend JavaScript files.
